# 分野別の現場基準

## 文章・SEO記事

- 顧客価値: 目的に対する理解、正確性、読みやすさ、読者の次の行動。
- 現物: 本文、構成、検索意図、参照資料、ユーザー指定条件、公開先の仕様。
- ムダ: 同じ主張の反復、情報を伴わない前置き、不要な見出し、過度な一般論。
- 残す品質: 根拠、定義、注意点、例外、読者が理解するための十分な説明。
- テスト: 数字・固有名詞・主張の保持、引用整合、読者の疑問への回答、文章の自然さ。
- 組み合わせ: 必要に応じて調査・日本語校閲・SEOの専門スキルに任せる。本スキルは工程と手戻りを診断する。

## コード・Webツール

- 顧客価値: ユーザーが目的を達成できること、正確・安全・速い・保守できること。
- 現物: ソース、テスト、実行ログ、ブラウザ確認、利用可能なベンチマーク。
- ムダ: 重複コード、不要な依存、過剰ネットワーク呼び出し、無意味な状態管理。
- 残す品質: エラー処理、セキュリティ、アクセシビリティ、観測性、後方互換性。
- テスト: 変更前後の同条件比較、既存テストと追加回帰テスト、エッジケース、リスク箇所。実行できないテストは未実施と表記。

## 調査・投資・分析

- 顧客価値: 意思決定に十分な正しい根拠、反証、再現性。
- 現物: 一次資料、出典、確認日、計算式、相反する証拠。
- ムダ: ソースの重複収集、結論に関係しない調査、同じ数字の転載。
- 残す品質: 出典、数字の計算条件、反証可能性、利益相反・リスク情報。
- テスト: 重要な主張の原典追跡、異なる仮説への感度。効果の数字は創作しない。

## タスク管理・業務運用

- 顧客価値: 迷いなく着手し、守るべき期限を守り、持続できる負荷。
- 現物: 実際のタスク一覧、所要時間、予定、締切、運用上の困難。
- ムダ: 同じ入力の繰り返し、増殖するラベル、機能過多、レビューの儀式化。
- 残す品質: 大事な期限、依存関係、本人が見たい全体像、無理のない余白。
- テスト: 操作数、維持負荷、再発率、必要時の検索性。「つらいのは気合不足」という判断をしない。

## 機密・安全領域

外部投稿、顧客データ、削除、送信、資金移動、法務・医療に関係する作業は、正確性、権限、リスク、人への影響を効率より優先。冗談演出を無効化。自動操作できない部分はテスト項目と操作手順を示すに留める。
