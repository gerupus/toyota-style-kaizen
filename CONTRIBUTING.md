# Contributing

Issues and PRs are welcome. Please distinguish verified Toyota/TPS sources from this project's original AI adaptation. Keep `SKILL.md` concise; detailed methods belong in references. Add tests for every CLI behavior change, including harmful input and rollback/recovery states. Never invent KPI values or claim agent autonomy without E2E evidence. Avoid trademarked art and confidential Toyota information. Document backward-incompatible schema changes and state migrations. Run `python -m unittest discover -s tests -v` before submitting.
