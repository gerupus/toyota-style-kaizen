# Changelog

## 1.0.0 (2026-10-20) — First public release candidate

- Rebuilt the previous private prototype as a portable, single-skill public repository.
- Added explicit opt-in installation, local workspace initialization, first-shift startup, event journal, memo projections, task state machine, review and WIP gates, local evidence and measurement records, deterministic comparison and integrity checks.
- Eliminated unsupported universal organization health score and automatic 'verified' classifications from prototype logic.
- Documented unsupported autonomous execution, approvals, background activity and production security.

The prior private preview labeled v1.2.0 was a separate design prototype and is **not** a semver predecessor of this newly initialized public release line.
